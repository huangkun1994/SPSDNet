# SPSDNet 

**Official PyTorch implementation of the paper "Self-Paced Learning Guided Self-Distillation Network for Medical Image Segmentation".**

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)
